# Spec Delta

## Purpose

定义每日登录、分享、激励视频和成就等非关卡奖励的领取条件与限制，提供可控且可审计的喵币补充来源。

## ADDED Requirements

### Requirement: 每日登录奖励必须按配置每日领取一次
系统 MUST 为符合条件的玩家提供每日登录奖励，并按配置确定奖励数额及每日重置边界。

#### Scenario: 首次登录领取当日奖励
- **WHEN** 玩家在当前奖励日首次进入游戏且满足登录奖励条件
- **THEN** 系统发放一次当日奖励并记录领取状态

#### Scenario: 重复登录
- **WHEN** 玩家在同一奖励日再次进入游戏
- **THEN** 系统不重复发放该日登录奖励

### Requirement: 分享奖励必须遵守每日次数上限
系统 MUST 限制每位玩家每日最多领取三次分享奖励，并仅在分享流程满足配置的有效完成条件后发奖。

#### Scenario: 有效分享且当日未达上限
- **WHEN** 玩家完成有效分享且当日已领取次数少于三次
- **THEN** 系统发放配置奖励并增加当日分享领取次数

#### Scenario: 当日分享奖励已达上限
- **WHEN** 玩家当日已领取三次分享奖励
- **THEN** 系统不再发放分享奖励

### Requirement: 激励视频奖励必须在有效观看后发放并限制次数
系统 MUST 仅在激励视频完成且平台回调通过校验后发放奖励，并限制每位玩家每日最多领取五次。

#### Scenario: 完成有效激励视频
- **WHEN** 玩家完成激励视频且有效完成回调通过校验
- **THEN** 系统发放配置奖励并记录该次领取

#### Scenario: 视频未完成或回调无效
- **WHEN** 玩家中断视频或平台完成回调未通过校验
- **THEN** 系统不发放奖励且不增加有效领取次数

#### Scenario: 达到每日激励视频上限
- **WHEN** 玩家当日已领取五次激励视频奖励
- **THEN** 系统不再提供可领取的激励视频奖励

### Requirement: 成就奖励必须每项只领取一次
系统 MUST 在玩家满足成就条件时开放对应奖励，并对每项成就记录唯一领取状态。

#### Scenario: 玩家完成尚未领取的成就
- **WHEN** 玩家满足一项成就条件且该奖励尚未领取
- **THEN** 系统发放配置奖励并将该项成就标记为已领取

#### Scenario: 重复满足已领取成就
- **WHEN** 玩家再次触发已领取成就的条件
- **THEN** 系统不重复发放该成就奖励

### Requirement: 奖励请求必须可重复提交而不重复发放
系统 MUST 对每日及成就奖励请求执行云端资格和去重校验，使网络重试或重复回调不会重复增加玩家余额。

#### Scenario: 奖励请求重复到达
- **WHEN** 云端收到同一奖励来源和领取周期的重复请求
- **THEN** 系统返回原处理结果且不再次增加玩家余额
