# Spec Delta

## Purpose

定义猫咪品种、稀有度、成长和收集解锁行为，使玩家能够通过关卡进度获得并培养不同特性的猫咪。

## ADDED Requirements

### Requirement: 每种猫咪品种必须具有可配置的收集资料
系统 MUST 为每个品种维护唯一标识、名称、稀有度、描述、状态衰减系数、疾病抗性、奖励加成和解锁条件，并在品种图鉴中展示品种资料。品种图鉴 MUST 以品种和收集状态为对象，不展示或管理某只已拥有猫咪实例的当前状态；单只猫咪实例详情从咪窝进入。

#### Scenario: 查看图鉴中的已拥有品种
- **WHEN** 玩家在图鉴中打开已拥有品种的资料
- **THEN** 系统展示该品种的描述、稀有度及影响猫咪状态或奖励的品种特性，不将资料页当作单只猫咪实例详情

### Requirement: 猫咪成长必须随有效经验增加
系统 MUST 为猫咪记录等级和当前经验，并在达到配置的升级条件时提升等级；升级不得重置猫咪的品种或拥有状态。

#### Scenario: 经验达到升级条件
- **WHEN** 猫咪获得经验且累计值达到当前等级的升级条件
- **THEN** 系统提升猫咪等级并保留超出阈值的剩余经验

### Requirement: 品种解锁必须遵守配置的进度条件
系统 MUST 仅向满足关卡等级、活动或其他已配置解锁条件的玩家开放对应品种，并避免重复授予已拥有的猫咪品种奖励。

#### Scenario: 达到关卡解锁条件
- **WHEN** 玩家首次达到某品种配置的解锁关卡
- **THEN** 系统开放对应的猫咪获取机会

#### Scenario: 查看未解锁品种
- **WHEN** 玩家查看尚未满足条件的品种
- **THEN** 系统展示该品种及其未满足的解锁条件，不允许提前获取

### Requirement: 猫咪选择必须限于当前可获得的候选项
当进度奖励要求玩家选择猫咪时，系统 MUST 展示三只符合本次解锁规则且玩家尚未拥有的候选猫咪，并在玩家选定后授予该猫咪。

#### Scenario: 玩家完成一次猫咪选择
- **WHEN** 玩家从三只有效候选猫咪中选择一只
- **THEN** 系统将所选猫咪加入玩家收藏且不授予其余候选猫咪

#### Scenario: 可选候选不足三只
- **WHEN** 符合条件且尚未拥有的候选猫咪不足三只
- **THEN** 系统仅展示所有符合条件的候选猫咪，不展示不符合解锁条件或已拥有的猫咪
