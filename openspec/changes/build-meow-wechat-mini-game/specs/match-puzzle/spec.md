# Spec Delta

## Purpose

为微信小游戏提供可重复游玩的连连看关卡体验，涵盖棋盘生成、路径匹配、特殊方块、局内道具与关卡结算。

## ADDED Requirements

### Requirement: 关卡棋盘必须由可配对的图片方块组成
系统 MUST 按关卡配置生成偶数数量的方块，并保证每种图片在棋盘上的出现次数为偶数。首个棋盘为 6×8；后续尺寸、图片种类数和机制由关卡配置决定。

#### Scenario: 生成包含重复图片的首关棋盘
- **WHEN** 系统开始生成 6×8 的首关
- **THEN** 棋盘包含 48 个方块，使用 6 至 8 种图片且每种图片出现偶数次

### Requirement: 玩家只能消除满足连线路径规则的相同方块
系统 MUST 仅在两块图片相同且连接路径无遮挡、拐点不超过两个时允许消除。路径可经过棋盘外侧的空白区域。

#### Scenario: 两块相同图片可通过两次转弯连接
- **WHEN** 玩家选择的两块图片相同且存在最多两个拐点的无遮挡路径
- **THEN** 系统显示连接路径并移除这两块方块

#### Scenario: 路径被方块阻挡或需要超过两个拐点
- **WHEN** 玩家选择的两块图片相同但不存在符合规则的路径
- **THEN** 系统保留方块并反馈本次匹配无效

### Requirement: 关卡必须防止棋盘进入无可执行匹配的状态
系统 MUST 在关卡开始时确保至少存在一组合法匹配；若局内没有合法匹配，玩家 MUST 能使用洗牌恢复至少一组合法匹配。

#### Scenario: 关卡开始时至少有一组合法匹配
- **WHEN** 系统完成棋盘生成
- **THEN** 棋盘上至少存在一组满足连线规则的方块

#### Scenario: 棋盘无合法匹配时洗牌
- **WHEN** 玩家使用洗牌道具且当前棋盘没有合法匹配
- **THEN** 系统重新排列剩余方块并保证至少存在一组合法匹配

### Requirement: 特殊方块按其关卡规则影响匹配
系统 MUST 支持关卡配置启用的冰块、锁链、翻转和移动方块，并在方块消除或状态改变时遵守对应解锁条件。

#### Scenario: 冰块需要额外操作
- **WHEN** 玩家首次合法连接带冰块的方块
- **THEN** 系统移除冰层但保留方块，后续合法连接才可移除方块

#### Scenario: 锁链由相邻消除解除
- **WHEN** 锁链方块满足关卡配置的相邻消除条件
- **THEN** 系统解除锁链并允许该方块按普通规则参与匹配

#### Scenario: 翻转方块揭示图片
- **WHEN** 玩家首次点击朝下的翻转方块
- **THEN** 系统显示其图片但不将该次点击视为匹配选择

#### Scenario: 移动方块按关卡计时移动
- **WHEN** 移动方块的配置间隔到达
- **THEN** 系统按关卡规则交换其位置，并保持方块图片及特殊状态不变

### Requirement: 关卡结算必须区分胜利与失败
系统 MUST 在清空全部方块时判定胜利，并在时间或步数限制耗尽且棋盘未清空时判定失败；结算至少展示结果、得分及本关奖励。

#### Scenario: 清空棋盘
- **WHEN** 玩家移除最后一块方块
- **THEN** 系统结束关卡并展示胜利结算

#### Scenario: 用尽时间或步数
- **WHEN** 本关时间或步数限制耗尽且仍有方块
- **THEN** 系统结束关卡并展示失败结算

### Requirement: 局内道具必须执行对应效果
系统 MUST 支持提示、洗牌、炸弹和加时道具，并在道具不可用或次数不足时不改变棋盘状态。

#### Scenario: 使用提示道具
- **WHEN** 玩家拥有提示次数并请求提示
- **THEN** 系统高亮一组当前合法匹配

#### Scenario: 使用炸弹或加时道具
- **WHEN** 玩家拥有对应道具并在关卡中使用
- **THEN** 炸弹移除其作用范围内符合炸弹规则的方块，加时增加关卡配置的时长
