# Spec Delta

## Purpose

为长期未获照料的猫咪提供自动收容、原主人限期赎回和期满后重新出售的生命周期，并保护玩家隐私及猫咪所有权的一致性。

## ADDED Requirements

### Requirement: 连续未喂食达到期限后猫咪必须自动进入收容所
系统 MUST 按每只猫最后一次成功喂食的服务端时间记录未喂食时长；达到连续 30 天时，系统 MUST 自动将该猫咪转入收容所，不以玩家是否登录作为条件。

#### Scenario: 玩家登录但持续未喂食
- **WHEN** 距猫咪最后一次成功喂食已满 30 天，即使玩家期间曾登录
- **THEN** 系统自动将该猫咪移入收容所并记录入所时间及原主人

#### Scenario: 期限前成功喂食
- **WHEN** 猫咪在连续 30 天期限到达前成功获得喂食
- **THEN** 系统更新最后喂食时间并从该时间重新计算期限

#### Scenario: 到达未喂食期限
- **WHEN** 当前服务端时间达到或超过猫咪最后一次成功喂食时间加 30 天
- **THEN** 系统仅执行一次自动入所状态转换并保留猫咪原有数据

### Requirement: 原主人必须能在收容首年内按双倍基准价赎回猫咪
系统 MUST 在猫咪入所后的首年内，仅允许记录的原主人按该猫配置的基准价两倍赎回；赎回成功须扣除喵币并将同一只猫归还给原主人。

#### Scenario: 原主人在首年内赎回
- **WHEN** 原主人在入所时间起一年内发起赎回、拥有足够喵币且有可用咪窝
- **THEN** 系统按配置基准价两倍扣除喵币，将该猫归还原主人并从收容列表移除

#### Scenario: 赎回条件不满足
- **WHEN** 原主人余额不足或没有可用咪窝时发起赎回
- **THEN** 系统拒绝赎回且不改变余额、猫咪所有权或收容记录

#### Scenario: 非原主人在首年内购买
- **WHEN** 其他玩家在猫咪入所未满一年时发起购买
- **THEN** 系统拒绝购买且不扣款

### Requirement: 首年期满后猫咪必须开放给其他玩家按配置低价购买
系统 MUST 在猫咪入所满一年且仍未赎回后，允许原主人以外的玩家按该猫配置的收容低价购买；原主人的赎回权在开放公开购买时终止。

#### Scenario: 入所未满一年时查询购买资格
- **WHEN** 其他玩家查询尚未入所满一年的猫咪
- **THEN** 系统将猫咪标记为尚不可公开购买

#### Scenario: 入所满一年后公开购买
- **WHEN** 其他玩家购买已入所满一年且仍可出售的猫咪，并且余额足够且有可用咪窝
- **THEN** 系统按配置收容低价扣款、将猫咪所有权转给该玩家并从收容列表移除

#### Scenario: 原主人在公开出售期内尝试赎回
- **WHEN** 原主人在入所满一年后尝试赎回该猫
- **THEN** 系统拒绝赎回且不改变猫咪状态

#### Scenario: 公开购买条件不满足
- **WHEN** 买家余额不足或没有可用咪窝
- **THEN** 系统拒绝购买且不改变余额、猫咪所有权或收容记录

### Requirement: 收容交易必须原子化并保护玩家隐私
系统 MUST 对赎回和公开购买执行服务端校验及原子所有权转移；收容列表仅展示必要的猫咪信息，不向其他玩家暴露原主人的身份标识。

#### Scenario: 多名玩家同时购买同一只猫
- **WHEN** 多个合格购买请求并发提交同一只可售猫咪
- **THEN** 系统仅确认一个交易，其他请求不得扣款或获得该猫

#### Scenario: 查看收容列表
- **WHEN** 玩家查看收容所中的猫咪
- **THEN** 系统展示品种、等级、收容时长和当前可执行的赎回或购买状态，但不展示原主人的公开身份标识
