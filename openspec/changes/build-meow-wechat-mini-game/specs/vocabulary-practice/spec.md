# Spec Delta

## Purpose

为后续阶段提供可分级的英语词汇练习，支持不同题型和按答题表现发放受每日上限约束的喵币奖励。

## ADDED Requirements

### Requirement: 玩家必须能按等级和题型练习词汇
系统 MUST 提供按配置等级选择词汇和练习模式的能力，至少支持看英文选中文、看中文选英文和拼写，并展示词义及可用例句或发音。

#### Scenario: 开始指定等级和题型的练习
- **WHEN** 玩家选择可用词汇等级和一种练习模式
- **THEN** 系统展示符合所选等级和模式的题目并接受对应形式的答案

#### Scenario: 当前词库无可用题目
- **WHEN** 玩家请求的等级或题型没有可用词汇
- **THEN** 系统提示暂无可用题目且不发放奖励

### Requirement: 答题奖励必须按正确答案和难度计算
系统 MUST 仅为正确答案发放按词汇难度配置的喵币奖励；连续答对十题时可额外发放配置的连对奖励。

#### Scenario: 正确回答词汇题
- **WHEN** 玩家提交与题目匹配的正确答案
- **THEN** 系统增加正确答题数并按该词汇难度计算待发喵币奖励

#### Scenario: 错误回答词汇题
- **WHEN** 玩家提交错误答案
- **THEN** 系统不为该题发放喵币并将连续答对计数清零

#### Scenario: 连续答对十题
- **WHEN** 玩家在同一练习进度中连续答对十题
- **THEN** 系统计入配置的连对奖励

### Requirement: 词汇练习每日奖励必须遵守总上限
系统 MUST 将词汇练习的答题奖励和连对奖励合并计入同一每日喵币上限；达到上限后可继续练习，但不得继续增加当日词汇奖励。

#### Scenario: 未达到每日上限
- **WHEN** 玩家答对题目且当日已发放词汇奖励低于 500 喵币
- **THEN** 系统发放本次奖励但不得使当日累计超过 500 喵币

#### Scenario: 奖励将超过每日上限
- **WHEN** 本次答题或连对奖励将使当日累计超过 500 喵币
- **THEN** 系统仅发放剩余可领取额度

#### Scenario: 当日词汇奖励已达上限
- **WHEN** 玩家当日词汇奖励累计已达到 500 喵币
- **THEN** 系统继续允许答题但不再增加词汇奖励，并在奖励重置后恢复发放
